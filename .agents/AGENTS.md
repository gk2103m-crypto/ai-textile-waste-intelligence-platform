# Repository Push Rules

Whenever committing or pushing code in this workspace, ALWAYS push to BOTH of the following repositories:

1. **Springboard Remote (Branch: `gk2103m-crypto`)**:
   `https://github.com/springboardmentor802-dotcom/AI-Textile-Waste-Intelligence-Platform.git`
   Command: `git push springboard main:gk2103m-crypto`

2. **Backup Remote (Branch: `main`)**:
   `https://github.com/gk2103m-crypto/ai-textile-waste-intelligence-platform.git`
   Command: `git push origin main`

### Configured Terminal Shortcut:
You or the AI assistant can simply run:
```bash
git pushall
```
This automatically pushes to both remotes in one command.
